# EarningsEdge

**AI-powered earnings intelligence.** Monitor quarterly earnings releases for your stock watchlist, receive automated AI analysis, and get instant Telegram notifications — all in one clean financial dashboard.

---

## Features

- **Watchlist Management** — Search any US-listed company and add it to your personal watchlist
- **AI-Powered Analysis** — Full structured earnings analysis generated by Claude with web search for live consensus data
- **Earnings Calendar** — Monthly calendar view showing upcoming earnings for all your watchlisted companies
- **History & Trends** — Timeline of past analyses per company with quality score charts and beat-rate statistics
- **Telegram Alerts** — Real-time notifications via Telegram Bot when a new analysis is ready
- **Verdict System** — Color-coded Beat / Inline / Miss verdicts with one-line summaries
- **Quality Score** — Earnings quality rating (0–10) based on FCF coherence, guidance visibility, and red flags
- **Red Flag Detection** — Automatic identification of accounting warnings, SBC inflation, DSO increases, etc.
- **Cron Monitoring** — Runs every 4 hours to detect newly reported earnings automatically

## How It Works — Agent Pipeline

### 1. Scan for New Earnings
The cron job (`/api/earnings/check`) runs every 4 hours via Vercel Cron. It fetches the earnings calendar from Financial Modeling Prep for all tickers on any user's watchlist, looking for earnings reported in the past 3 days that haven't been analyzed yet.

### 2. Fetch Financial Data
For each new earnings release, the pipeline fetches from FMP in parallel:
- Income statement (5 quarters)
- Balance sheet (5 quarters)
- Cash flow statement (5 quarters)
- Analyst consensus estimates

### 3. Find Consensus via Web Search
The Claude API call includes the `web_search_20250305` tool, enabling Claude to search live sources (Yahoo Finance, MarketWatch, Seeking Alpha, Bloomberg) for:
- Current analyst consensus estimates for revenue and EPS
- Initial market reaction (after-hours price movement)
- Management guidance commentary
- Recent analyst price target changes

### 4. Generate AI Analysis
Claude synthesizes the structured financial data with live consensus data to produce:
- Beat / Inline / Miss verdict with one-line summary
- Key metrics table with Reported vs Consensus vs Year-Ago
- "What Stood Out" — top positives and negatives
- Guidance update — raised / maintained / lowered
- Red flags — accounting quality warnings
- Quality score (0–10)
- Sources with links

### 5. Send Alert & Save
The analysis is saved to Supabase, the watchlist entries are updated with the new verdict, and Telegram alerts are dispatched to all users who watch that ticker and have Telegram enabled.

## Setup

### 1. Clone and install

```bash
git clone https://github.com/your-org/earningsedge.git
cd earningsedge
npm install
```

### 2. Configure environment variables

```bash
cp .env.example .env.local
```

Edit `.env.local` with your actual keys (see [Prerequisites](#prerequisites)).

### 3. Set up Supabase

1. Create a new Supabase project
2. Open the SQL editor in your Supabase dashboard
3. Run the migration:

```bash
# Paste the contents of supabase/migrations/001_initial_schema.sql
# into the Supabase SQL editor and click Run
```

### 4. Set up Telegram Bot

1. Message [@BotFather](https://t.me/BotFather) on Telegram
2. Send `/newbot` and follow the prompts
3. Copy the bot token to `TELEGRAM_BOT_TOKEN` in your `.env.local`
4. After deploying, register the webhook:

```bash
curl -X POST "https://api.telegram.org/bot<TOKEN>/setWebhook" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://your-domain.vercel.app/api/telegram/webhook"}'
```

### 5. Run locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### 6. Deploy to Vercel

```bash
npm install -g vercel
vercel --prod
```

Set all environment variables in the Vercel dashboard under **Settings → Environment Variables**.

The `vercel.json` cron is automatically picked up — it runs `/api/earnings/check` every 4 hours.

## Environment Variables

```bash
ANTHROPIC_API_KEY=          # Anthropic API key
FMP_API_KEY=                # Financial Modeling Prep API key
TELEGRAM_BOT_TOKEN=         # Telegram Bot token from @BotFather
SUPABASE_URL=               # Supabase project URL (server-side)
SUPABASE_ANON_KEY=          # Supabase anon key (server-side)
SUPABASE_SERVICE_ROLE_KEY=  # Supabase service role key (for cron/webhooks)
NEXT_PUBLIC_SUPABASE_URL=   # Same URL, exposed to browser
NEXT_PUBLIC_SUPABASE_ANON_KEY= # Same anon key, exposed to browser
NEXT_PUBLIC_APP_URL=        # Your deployed app URL (for deep links)
CRON_SECRET=                # Random secret to secure cron endpoint
```
